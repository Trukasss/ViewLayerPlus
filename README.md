# Seamlessly extend View Layers operations !

This addon helps the compositing/rendering process in three ways:

___
## 1. COMPOSITING 
![menu](/presentation/presentation_menu.png) ![contextual_menu](/presentation/presentation_contextual.png)

This addon discreetly adds a new "View Layer" menu in the compositor panel and new entries in the right-click contextual menu for easier access with the following operators:

> 1. Enable View Layers for selected render layers
> 2. Disable View Layers for selected render layers
> 3. Enable all View Layers
> 4. Disable all View Layers
> 5. Enable View Layers for unmuted render layers nodes only (press M to mute a node)
> 6. Enable View Layers for selected render layers only
> 7. (Bonus) Switch to View Layer of the selected render layer

___
## 2. MANAGER
![manager](/presentation/presentation_manager.png)

This addon also allows you to manage your View Layers like any other Blender lists:

> 1. Switch to a View Layer 
> 2. Enable/Disable View Layer
> 3. Add/Remove View Layer
> 4. Special Menu for more sorting options
>     - Sort by name
>     - Sort by name in reverse
>     - Move to top
>     - Move to bottom
> 5. Move Layer up or down
> 6. Copy/Paste from one Layer to another
>     - All Layer Collection render settings
>     - View Layers passes (with Eevee and Cycles support)
>     - AOVs
>     - (and more to come)

___
## 3. OUTLINER
![outliner](/presentation/presentation_outliner.png)
![outliner_menu](/presentation/presentation_outliner_menu.png)

Finally, it adds a quick way to copy from the outliner the selected Collections render settings:

> 1. Copy selected Layer Collections render settings (exclude, holdout, indirect_only, hide_viewport) to selcted View Layers
